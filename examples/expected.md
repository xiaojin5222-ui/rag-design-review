# 审核者参考答案

此处是答案文件，独立行为测试的 Agent 不应读取。

当前实现按题设完成原文选择；`expected.json` 列出独立预设结果。春季公开版的起止日都应命中；四月切换新版；会员和工作人员各自看到允许范围内最新记录；游客不会看到这两类私有条目；无主题、全部过期或空资料返回 `null`。输入和返回值不共享可变记录，非法日期及未知角色明确拒绝。

不应因该案例名叫 RAG 就引入模型或向量库；也不能把传入 role 的过滤演示称为身份认证。`published_at` 只是题设排序字段，不代表资料能在当时被系统获得；该例没有模拟历史系统快照。没有覆盖文件解析、向量召回、生成答案、真实权限服务、并发或生产延迟。

`check.py` 是固定合成行为检查，不调用 Agent、不衡量 skill 净增益、不证明端到端业务成功。检查器只读本目录，不创建持久化输出；可安全重复运行。
