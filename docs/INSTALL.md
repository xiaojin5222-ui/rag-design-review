# 安装与使用

本指南安装的是独立 `rag-design-review` skill，不要求安装其他 skill，也不写入全局配置或用户级 skill 目录。先选择一个可以自行管理的项目目录。

## 文件与依赖

最小运行内容位于仓库根目录：

```text
rag-design-review/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── LICENSE
```

`SKILL.md` 是任务指南；`agents/openai.yaml` 是显示名称和默认提示等元数据，不会创建工具连接或赋予权限。复制分发时保留 `LICENSE` 中的署名和许可文本。

| 使用方式 | 条件 |
| --- | --- |
| 阅读指南、设计方案、分析已给文本 | 能读取并执行 skill 指令的宿主；用户提供资料，不需要本包专用 API key |
| 读取图片、PDF、表格或现有项目 | 宿主具备相应读取工具；具体格式和项目依赖由使用环境决定 |
| 复现错误或执行修复 | 对应代码运行环境和当前任务授权；本包不会自动安装项目依赖 |
| 运行本仓库合成示例 | Python 3.9+ 与标准库；无需联网、模型 API 或向量数据库 |

## 在 Codex 中按项目安装

当前官方文档列出的仓库级位置是项目内 `.agents/skills/`；Codex 会按工作目录与仓库边界发现这些目录。以你的安装版本文档为准，本项目的实际验证状态另见 [VALIDATION.md](VALIDATION.md)。[官方技能说明](https://learn.chatgpt.com/docs/build-skills)（2026-10-24 核对）

1. 从对应版本的仓库或 Release 取得文件，确认版本、来源和包内容。若发布页提供校验值，先核对；不要从来历不明的镜像运行安装脚本。
2. 检查当前项目及宿主可见目录中是否已经有 `rag-design-review`。同名项存在时先停止，核对来源和用户改动，不覆盖或合并。
3. 在目标项目中创建 `.agents/skills/rag-design-review/`，复制根目录的 `SKILL.md`、整个 `agents/` 和 `LICENSE`。也可以复制整个已核验的发行目录；其额外文档和示例不会成为运行时依赖。不要把 `.git`、私有测试记录或本机配置带入安装目录。
4. 检查目录层级，避免出现 `rag-design-review/rag-design-review/SKILL.md` 这样的多余一层。

安装后的项目结构应是：

```text
your-project/
└── .agents/
    └── skills/
        └── rag-design-review/
            ├── SKILL.md
            ├── agents/
            │   └── openai.yaml
            └── LICENSE
```

这一步只涉及你选择的项目目录。无需修改 `~/.codex/config.toml`、用户级技能目录或其他项目。

## 确认加载

在该项目内打开一个新会话，检查宿主是否能选到 `rag-design-review`，再明确调用它。Codex CLI/IDE 支持通过技能选择入口或 `$rag-design-review` 指定；其他界面的操作以该版本为准。[官方调用说明](https://learn.chatgpt.com/docs/build-skills)

```text
请用 $rag-design-review 审核这套知识库方案。
本次只做设计审阅；请区分已有证据和未验证项，不改文件、不调用业务接口。
```

文件存在或助手复述了名称，不足以证明原生加载。核对宿主实际展示的技能及加载记录，并保存所用版本。未出现时先检查目录层级、工作目录和同名冲突；重新打开会话或重启宿主后再查，不要通过重复复制到多个全局位置来碰运气。

若宿主不能原生加载，可明确让助手读取 `SKILL.md` 后按其工作；这属于手动提供指令，不能记录成原生发现或自动触发验证。其他宿主未测试，不承诺兼容。

## 单独运行示例

无需先安装 skill。在仓库或完整发行目录根部运行：

```sh
python3 -I -B examples/check.py
```

检查器按自身路径读取示例，不要求个人目录或外部服务；不修改原资料和历史记录。它执行的是本地合成检索函数检查，没有调用模型，结果不能替代实际 Agent 行为评审。详情见 [验证记录](VALIDATION.md)。

## 升级与卸载

升级前对比变更记录并保留自己的修改。先把已安装目录完整移到宿主技能扫描范围以外的备份位置，再按安装步骤放入新版本；不要原地覆盖，也不要把旧版本换个目录名留在同一扫描范围造成同名冲突。确认新版本可用后再决定是否删除备份。

卸载时，只移走或删除本次创建的项目级 `.agents/skills/rag-design-review/`。如果安装后自行新增了文件，先备份。随后重新打开会话并检查是否仍从其他位置加载了同名 skill；不要连带删除 `.agents/skills/` 下其他内容。

安装和卸载都不会自动修改业务数据、知识库索引或线上系统。
